# SampleWebApp

A sample web application project built with Java and HTML. This repository is intended for demonstrating a Jenkins-based build and continuous integration workflow.

## Project Overview

SampleWebApp provides a simple Java-backed web application with an HTML user interface. It can be used as a starting point for learning web application development and automating builds with Jenkins.

## Technologies

- **Java** — application logic
- **HTML** — web interface
- **Jenkins** — continuous integration and build automation

## Getting Started

### Prerequisites

- Java Development Kit (JDK)
- A web server or servlet container appropriate for the project
- Jenkins, if you want to run the CI pipeline

### Running the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/param1995/SampleWebApp.git
   cd SampleWebApp
   ```

2. Build and run the application using the project's configured Java build process or IDE.

3. Open the application in your browser using the URL provided by your local server.

## Jenkins Integration

This project can be connected to Jenkins to automate checkout, builds, testing, and deployment. Configure a Jenkins job or pipeline to use this repository as its source-control project.
